## 주의할 점·알려진 문제

- 카메라는 HTTPS 또는 내 PC에서 연 파일에서만 사용할 수 있습니다.
- `<script type="module">`은 금지입니다. 일반 스크립트는 설계도의 순서대로 불러옵니다.
- `sb_secret_`으로 시작하는 Supabase 비밀 키는 브라우저 코드에 넣지 않습니다.
- 업로드만 허용하는 정책으로는 웹 화면에서 사진을 삭제할 수 없습니다. 현재 설계는 Supabase 대시보드에서 직접 삭제하는 방식입니다.
- `photos` 버킷이 공개이면 QR 주소를 아는 사람이 사진을 볼 수 있습니다. 확장 C 시작 전에 공개 범위와 삭제 방법을 안내하고 확인해야 합니다.
- `AGENTS.md`의 폴더 구조 설명에는 `camera.js`가 1단계부터 사용된다고 적혀 있어, 이번 요청의 “카메라 분리는 확장 A부터”와 다릅니다. 이후 문서 정리 시 이 안내를 맞춰야 합니다.
- 브라우저 자동 확인은 수행하지 못했습니다. 실제 카메라 사용은 HTTPS 또는 로컬 파일 환경에서 확인해야 합니다.
- Canvas(브라우저에서 그림을 담는 화면)의 픽셀 읽기는 보안·브라우저 환경에 따라 실패할 수 있으며, 이 경우 결과 화면에 한국어 오류를 표시합니다.
