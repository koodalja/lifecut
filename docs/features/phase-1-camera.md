# 1단계: 촬영하고 사진 확인하기

## 목표

촬영 버튼을 누르면 카메라를 연결하고 5초를 센 뒤 사진 한 장을 찍어 화면에서 확인합니다.

## 사용자 이야기

사용자로서 촬영 버튼을 눌러 잠깐 준비한 뒤 사진을 찍고, 찍힌 사진을 화면에서 확인하고 싶습니다.

## 화면 흐름

1. 촬영 버튼을 누릅니다.
2. 브라우저가 카메라 권한을 요청하면 허용합니다.
3. 화면에 카메라 영상과 5초 카운트다운이 표시됩니다.
4. 카운트다운이 끝나면 사진 한 장을 찍어 결과 화면에 표시합니다.
5. 다시 촬영 버튼을 눌러 새 사진을 찍을 수 있습니다.
6. 카메라 연결이나 촬영에 실패하면 한국어 안내를 확인합니다.

## 완료 기준

- [ ] 촬영 버튼을 눌렀을 때 카메라 권한 요청과 연결이 시작된다.
- [ ] 카메라 연결 후 화면에 5, 4, 3, 2, 1 순서로 숫자가 표시된다.
- [ ] 카운트다운 후 카메라에서 사진 한 장을 찍는다.
- [ ] 촬영한 사진이 화면에서 확인된다.
- [ ] 촬영 완료 후 카메라 영상이 꺼지고 다시 촬영할 수 있다.
- [ ] 권한 거부, 카메라 없음, 지원하지 않는 환경 등의 오류가 한국어로 표시된다.
- [ ] 사진 촬영 기능의 구현 파일은 `index.html`, `style.css`, `js/app.js` 세 개뿐이다.
- [ ] JavaScript 모듈 스크립트를 사용하지 않는다.

## 이번에 하지 않을 것

- 별도 `js/camera.js` 파일로 카메라 기능 분리 (확장 A)
- 사진 필터 (확장 B)
- Supabase 업로드와 QR 코드 (확장 C)
