# 확장 B: 촬영 후 사진 필터

## 목표

촬영이 끝난 결과 화면에서 필터를 고르면 사진 색이 바로 바뀌고, 원본 필터를 골라 처음 사진으로 돌아갈 수 있습니다. 필터를 바꿔도 흰 프레임 바탕과 프레임 글씨는 그대로 유지합니다.

## 사용자 이야기

사진을 찍고 난 뒤 여러 분위기의 필터를 비교해 고르고, 마음이 바뀌면 원본 사진으로 되돌리고 싶습니다.

## 화면 흐름

1. 2컷 또는 4컷 촬영을 끝내면 결과 화면으로 이동합니다.
2. 결과 프레임 위에 "필터를 골라 보세요" 안내와 가로로 움직이는 필터 버튼 한 줄을 봅니다.
3. `원본`, `흑백`, `세피아`, `따뜻하게`, `시원하게`, `화사하게` 중 하나를 누릅니다.
4. 선택 즉시 사진 부분만 선택한 색으로 바뀝니다. 흰 프레임 바탕과 `인생네컷`·날짜 글씨는 유지됩니다.
5. `원본`을 누르면 촬영 직후 사진의 색으로 돌아갑니다.
6. 다른 필터를 누르면 저장된 원본 사진에서 다시 색을 계산합니다. 필터를 연달아 적용해 화질이 누적해서 떨어지지 않습니다.

## 완료 기준

- [ ] 결과 화면 사진 위에 "필터를 골라 보세요" 안내 문장이 표시된다.
- [ ] 필터 선택 상자가 `div#filters`로 존재하고 필터 버튼은 JavaScript가 목록에서 자동으로 만든다.
- [ ] 여섯 필터가 `원본`, `흑백`, `세피아`, `따뜻하게`, `시원하게`, `화사하게` 순서로 나타난다.
- [ ] 필터 버튼은 알약 모양으로 가로 한 줄에 놓이고, 작은 화면에서는 좌우로 스크롤할 수 있다.
- [ ] 누른 필터 버튼에만 `.active`가 적용되어 진한 색으로 선택 상태가 표시된다.
- [ ] 필터 선택 즉시 결과 사진이 선택한 색으로 바뀐다.
- [ ] `원본` 필터를 누르면 원본 색으로 돌아간다.
- [ ] 필터 변경은 원본 사진 목록에서 매번 새 캔버스로 계산하며 원본 사진을 수정하지 않는다.
- [ ] 프레임의 흰 바탕, `인생네컷` 글씨와 날짜는 필터 선택 전후 동일하게 유지된다.
- [ ] 필터 기능에서 오류가 나면 결과 화면에 한국어 안내가 표시된다.
- [ ] `<script type="module">`을 사용하지 않고 `camera.js` → `frame.js` → `filters.js` → `app.js` 순으로 불러온다.

## 이번에 하지 않을 것

- 사진 다운로드, Supabase 업로드, QR 코드 (확장 C)
