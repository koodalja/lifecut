# 확장 A: 2컷/4컷 촬영과 세로 프레임

## 목표

2컷 또는 4컷을 선택하고 촬영 시작 버튼을 한 번 눌러 선택한 수만큼 사진을 찍습니다. 촬영한 사진은 위에서부터 흰 세로 프레임에 배치하고 아래에 서비스 이름과 오늘 날짜를 넣어 보여 줍니다.

## 사용자 이야기

사용자로서 2컷 또는 4컷을 골라 촬영을 시작한 뒤, 진행 상황과 찍힌 사진을 확인하고 완성된 세로 프레임을 받고 싶습니다.

## 화면 흐름

1. **컷 수 고르기:** 2컷 또는 4컷 버튼을 누릅니다. 각 버튼에는 컷 수를 알 수 있는 작은 프레임 그림이 있습니다.
2. **촬영하기:** 시작 버튼을 한 번 누릅니다. 각 사진마다 5초를 세고 촬영하며, 다음 촬영까지 0.7초 기다립니다. 촬영 중 `현재 컷 / 전체 컷`을 보여 주고, 찍힌 사진은 작은 미리보기로 쌓입니다.
3. **결과 확인:** 모든 촬영이 끝나면 흰 바탕의 세로 프레임을 보여 줍니다. 사진은 4:3 비율로 위에서부터 배치하고, 프레임 아래쪽에 `인생네컷`과 오늘 날짜를 표시합니다.
4. **처음으로:** 처음으로 버튼을 누르면 컷 수 선택 화면으로 돌아가 새 촬영을 시작할 수 있습니다.

## 완료 기준

- [ ] 컷 수 선택 화면에 2컷과 4컷 버튼이 표시된다.
- [ ] 두 버튼 모두 작은 프레임 그림으로 선택할 컷 수를 알아볼 수 있다.
- [ ] 시작 버튼 한 번으로 선택한 수만큼 촬영이 자동으로 이어진다.
- [ ] 각 사진을 찍기 전에 5, 4, 3, 2, 1 카운트다운이 표시된다.
- [ ] 이어지는 촬영 사이에 약 0.7초 기다린다. 마지막 촬영 뒤에는 기다리지 않는다.
- [ ] 촬영 중 현재 컷과 전체 컷이 `1 / 4`와 같은 형식으로 표시된다.
- [ ] 이미 찍은 사진이 촬영 중 작은 미리보기로 표시된다.
- [ ] 선택한 수만큼 촬영한 뒤 결과 화면으로 자동 이동한다.
- [ ] 결과 프레임은 흰 바탕의 세로 한 장이고 사진이 위에서부터 4:3 비율로 놓인다.
- [ ] 결과 프레임 아래에 `인생네컷`과 오늘 날짜가 표시된다.
- [ ] 처음으로 버튼을 누르면 컷 선택 화면으로 돌아가고 새 선택과 촬영을 할 수 있다.
- [ ] 카메라 권한 거부나 촬영 오류가 발생하면 한국어 안내가 표시되고 카메라가 꺼진다.
- [ ] JavaScript는 일반 스크립트로 연결되며 `<script type="module">`을 사용하지 않는다.
